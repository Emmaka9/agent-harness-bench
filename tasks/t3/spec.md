CSV Aggregator

Create `src/aggregate.js` exporting a single named ESM function, `aggregate(csvText, opts)`: parse RFC 4180-style CSV text and compute grouped aggregates. Node.js builtins only, no external packages. ESM.

`opts = {groupCol, valueCol, ops}`; `groupCol` and `valueCol` are column names from the header row; `ops` is an array drawn from `"count"`, `"sum"`, `"min"`, `"max"`, `"mean"`.

Parsing. Fields are separated by commas. A field may be wrapped in double quotes; a quote opens a quoted section only as the first character of a field. Inside a quoted section, a doubled quote (`""`) is one literal quote character, a single quote closes the section, and commas, CR, LF, and CRLF lose their special meaning. After the closing quote, characters up to the next comma or line break are appended literally. A quote elsewhere in an unquoted field is a literal character. Line breaks may be LF, CRLF, or a lone CR, in any mix; CRLF counts as one line break. There are no other escape sequences. Rows are separated by a line break that is not inside a quoted section. Empty lines (a line break immediately followed by a line break, with nothing at all between them) are skipped wherever they appear; a line consisting only of `""` or only of `,` is not empty and is a real row. The first non-empty line is the header row; if the input contains no non-empty line, there is no header row and the result is `[]`. The input may end with or without a trailing line break. A row with more or fewer fields than the header is malformed and is silently skipped. Leading and trailing whitespace of an unquoted field is NOT trimmed. Duplicate column names in the header are not special-cased; the first column with a given name wins.

Aggregation. `aggregate` returns an array of objects, one per distinct group value, in order of first appearance. Each result object has `group: <groupValue>` (the raw group string) plus one property per requested op, in the order the ops appear in `ops`. `count` may be requested like any other op and occupies the position it is given; an op omitted from `ops` has no property. `count` is the number of data rows in the group, including rows whose value fails to parse. The other ops aggregate over only the rows whose value parses as a finite number: `sum` (numeric total), `min`/`max` (extremes), `mean` (`Math.round(sum / n * 1000) / 1000`, `n` = parsed value count). Values are parsed with `Number(value.trim())`; an empty string, `NaN`, and infinities count as parse failures. When no row in the group has a parseable value: `sum` is `0`, `min`/`max`/`mean` are `null`. If `groupCol` or `valueCol` is not a header column name, the result is `[]`.
